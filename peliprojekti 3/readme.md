Jalokivien louhintapeli
Yu Yu Khaing

Pelissä näkyy päävalikko, jossa on neljä eri vaihtoehtoa pelaajan valittavana. 1. Jalokivien etsiminen tietokoneen satunnaisjärjestelmällä ja niiden kerääminen listaan. 2. Kerättyjen jalokivien näyttäminen tai niiden keräämättä jättäminen. 3. Kerättyjen jalokivien myyminen eri hinnoilla ja lisääminen rahaan (saldoon) sekä kokonaissumman näyttäminen. 4. Poistuminen tai pelaamisen lopettaminen. Peli toistaa päävalikkoa, kunnes pelaaja valitsee vaihtoehdon 4 poistuakseen.
